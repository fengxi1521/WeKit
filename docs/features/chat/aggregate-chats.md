# 对话归拢

入口：XiaoFeng 设置 → 功能 → 聊天 → 对话归拢。

将多个对话放入首页的归拢文件夹，显示汇总未读状态。点击功能管理文件夹：新建、编辑、删除或重载索引。

文件夹支持手动选择、自动所有群聊、自动所有公众号，以及自定义 SQL 规则。手动文件夹可从对话菜单加入或移出成员；自动规则的文件夹不能手动添加。SQL 设置页提供字段与 WHERE 示例。

可配合[添加对话至归拢文件夹](add-to-aggregation-folder.md)使用。自定义文件夹头像需要[自定义好友本地头像](../contacts/custom-local-friend-avatars.md)。保存后按页面提示重启微信，确保索引和显示同步。

文件夹管理页顶部提供「导出备份」与「导入备份」，导出全部文件夹（名称、类型、成员、SQL 规则、置顶标记）为 JSON 文件；导入时按文件夹 ID 合并，已有的同 ID 文件夹会被备份内容覆盖，非归拢 ID 或空名称的条目会被跳过。
